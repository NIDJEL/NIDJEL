## Open Source Highlight · Go Standard Library

### Go Standard Library Contributor

Contributed a concurrency fix to the official [`database/sql`](https://pkg.go.dev/database/sql) package. The change corrects a **lost-wakeup condition** in `closingMutex` writer coordination that could deadlock `Rows.Next` against a concurrent `Rows.Close`.
